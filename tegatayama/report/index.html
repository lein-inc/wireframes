02

ホームページの役割は、訪れた方を予約・お電話・お問い合わせまで迷わずご案内することです。9月に来訪した1,410人が、どこまで進んだかをまとめました。

入口 3

11件

腹腔鏡手術受付・採用応募フォーム。開いた77人のうち入力を始めたのは20人で、7割以上が入力前に離れています。

よく見られている「診察について」「休診日のお知らせ」「ペットパス」は、来院を決める直前に確かめるページです。ここから迷わず予約・お電話へ進める形に整えることが、成果を増やすいちばんの近道です。なお、スマホのメニュー内にある「診察について」ボタンはリンク先が空のままで、押しても移動しません。

03

地域での見つかりやすさ（MEO）

「近くの動物病院」を探す飼い主さまの多くは、ホームページより先にGoogleマップで比べます。地図での見え方を整えることをMEO（マップ検索対策）といいます。地域に根ざした病院にとって、効果の大きい集客の場です。

Googleマップの掲載状況

  • 未登録
    オーナー登録

    掲載に「ビジネスオーナーですか？」と表示されており、病院で情報を編集できない状態です。

  • 食い違い
    営業時間

    地図では「毎日9:00〜（水曜定休）」。ホームページのお知らせでは「午前は9:30〜、日曜午前は手術日のため休診」です。

  • できない
    口コミへの返信

    67件の口コミに返信できません。厳しい口コミにも病院の考えを伝えられない状態です。

  • 掲載あり
    住所・電話・ホームページ

    正しく表示されています。

運用でお困りの点はありませんか

  • 診療が忙しく、文章を書く時間がとれない
  • どの症例を載せればよいか迷う
  • 写真の選び方や、飼い主さまの了解の取り方が分からない
  • 管理画面での入力・公開の手順が分かりにくい
  • 専門的な内容を、飼い主さま向けにどこまでかみ砕くか迷う
  • 書いても読まれているのか分からない

※ 当てはまるものをお聞かせください。お困りの点に合わせて、下の改善方法を組み合わせます。

改善方法の案

案 A

書く項目を決めた
入力の型を用意

「病気の説明・診断・治療・経過」の4項目と写真欄を最初から並べた入力ひな形を用意します。空欄を埋めるだけで、いまの記事と同じ形になります。

病院：項目を埋める ／ 当社：ひな形の設定

聞き取りから
当社が原稿を作成

月1回、先生に10〜15分ほどお話を伺い、当社が原稿にまとめます。先生は内容の確認と写真の提供だけで済みます。

病院：お話・確認・写真 ／ 当社：原稿・入力・公開
案 C

1本をGoogleマップや
SNSにも活用

公開した症例を、Googleマップの投稿やThreadsでも短く紹介します。1回の作業で、地図・SNS・ホームページの3か所に届きます。

病院：なし ／ 当社：要約・投稿

目標は2か月に1本から。腹腔鏡手術の症例が増えると、「犬 腹腔鏡 秋田」のように専門の治療を探している飼い主さまに見つけてもらいやすくなり、遠方からの来院にもつながります。

05

サイトの健康状態

  • 正常
    サイトの表示

    8月20日〜23日の停止は23日に復旧済み。現在は全ページ正常に表示されています。

  • 正常
    WordPress本体・SSL（通信の暗号化）

    本体は最新の7.1.2に自動更新済み。SSLは2026年11月28日まで有効で、自動で更新されます。

  • 要対応
    プラグイン（追加機能）

    16本のうち13本が更新待ちで、自動更新もされない設定です。本体だけが更新され、プラグインが古いまま残る状態は、8月の停止と同じ構造です。

  • 要対応
    お問い合わせフォーム・ログイン保護

    サーバーの実行環境（PHP）が古く、フォームの機能を最新版に更新できません。不正ログインを防ぐ機能も停止したままです。

  • 要対応
    仮の投稿が公開のまま

    制作時の「タイトルが入ります」という仮の記事が公開されています（9月に4人が閲覧）。非公開にします。

※ プラグインの状況は2026年9月10日時点の確認です。
